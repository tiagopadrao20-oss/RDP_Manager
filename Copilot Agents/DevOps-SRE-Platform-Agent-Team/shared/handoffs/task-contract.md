# Task Handoff Contract

## Payload mínimo do Team Leader para especialistas
- `task_id`:
- `objective`:
- `business_impact`:
- `environment` (DEV/INT/CONS/PROD):
- `constraints` (janela, compliance, dependências):
- `artifacts` (ficheiros, pipelines, logs, dashboards):
- `definition_of_done`:
- `deadline`:

## Output obrigatório de cada especialista
1. **Assessment**: diagnóstico e causa provável.
2. **Plan**: passos com ordem de execução.
3. **Risks**: riscos + mitigação.
4. **Validation**: como comprovar sucesso.
5. **Rollback**: como desfazer com segurança.
6. **Decision**: recomendação final (Go / No-Go).

## SLA interno sugerido
- Triagem inicial: até 5 min.
- Proposta técnica: até 15 min.
- Consolidação Team Leader: até 10 min.
